# Overview

This sample set is the content behind the GitHub Docs web part. The page you are reading is `samples/index.md`. The tree on the left comes from `samples/toc.yml`.

Edit the files in GitHub. SharePoint does not store a second copy of the article.

## What the page does

1. Read `toc.yml` and build the tree.
2. Open the Markdown file for the selected node.
3. Render it in the page. There is no iframe.

A change in GitHub shows up after the cache interval, or immediately when you use **Refresh**.

## Try the sample

Point a page at this repository and set the TOC path to `samples/toc.yml`. The next pages show the TOC shape, the Markdown the renderer accepts, and how a private repository is read.
