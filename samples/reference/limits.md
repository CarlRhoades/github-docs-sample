# Limits

This version is a reader.

1. There is no search across the pages. The filter box matches titles in the tree only.
2. There is no editor in SharePoint. Change the Markdown in GitHub.
3. There is one language.
4. There is no scheduled sync. The web part reads GitHub when the page opens, then keeps the file in the browser session until the cache interval ends.
5. A second `toc.yml` included from the first one is not loaded. One TOC file describes the tree.
6. The page does not list branches. Create another page, or change the branch setting, to read a different branch.

Code blocks and wide tables scroll sideways when a line is wider than the column. The article itself uses the page scroll.
